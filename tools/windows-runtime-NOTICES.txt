Pet Dock Windows launcher and installer notices
===============================================

This notice covers only the generated `PetDock.exe` launcher and the NSIS
installer executable. It does not replace the runtime component provenance or
third-party notices supplied with the embedded Python runtime.

No compiler, linker, NSIS build tool, or MinGW development file is distributed
with Pet Dock. The source needed to reproduce the launcher and installer is in
`tools/windows_launcher.c`, `tools/installer.nsi`, and
`tools/build_installer.py`.
